# Lead My Property 🏡

Lead My Property is a modern, high-conversion real estate lead generation platform. It connects property developers, agencies, and individual agents with genuine prospective buyers and sellers to accelerate their business growth.

## ✨ Features

- **AI-Powered Leads:** Smart lead generation delivering the most promising prospects.
- **High Conversion Rates:** Meticulously qualified leads designed to close deals.
- **Organic & Genuine:** Authentic client connections for sustainable growth.
- **Lead Replacement Guarantee:** Unqualified leads are replaced to ensure maximum value.

## 🚀 Tech Stack

- **Frontend:** HTML5, Vanilla JavaScript
- **Styling:** Custom CSS (Modern UI/UX with smooth micro-animations, particle backgrounds, and glassmorphism)
- **Design Aesthetic:** Premium dark mode layout with responsive design for all devices.

## ⚙️ Setup & Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/2005anurag/lead-my-property.git
   ```

2. **Open the project:**
   Navigate into the directory and simply open `index.html` in your favorite web browser to view the application.
   ```bash
   cd lead-my-property
   start index.html
   ```
